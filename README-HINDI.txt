APNA AI - Android APK project

Package ID: com.intiyajalam.apnaai
Version: 1.0.1
Website: https://intiyajalam99735-art.github.io/APNA-AI/

APK banane ka free tareeqa:
1. GitHub par naya repository banayein: APNA-AI-ANDROID
2. Is ZIP ke andar ke sabhi files/folders repository ke main (root) mein upload karein.
3. GitHub repository mein Actions tab kholein.
4. 'Build Apna AI APK' workflow select karein.
5. 'Run workflow' dabayein. Build complete hone dein.
6. Successful run kholkar Artifacts mein 'Apna-AI-debug-APK' download karein.
7. ZIP extract karke app-debug.apk Android phone mein install karein.

Note:
- Ye debug APK personal testing/installation ke liye hai.
- Play Store ke liye release signing alag se chahiye.
- Purani APK ka update tabhi hoga jab uska package ID aur signing key match kare.
- App website ko internet se load karta hai; website online rehni chahiye.
- index-preview.html sirf reference copy hai; app live GitHub Pages URL kholta hai.
